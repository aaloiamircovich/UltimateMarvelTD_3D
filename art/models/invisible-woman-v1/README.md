# Invisible Woman · campo de cobertura

Modelo generado con Meshy desde la referencia del usuario, con traje azul, hombros blancos, guantes, botas y emblema de los Cuatro Fantásticos. Blender prepara una postura de cobertura y el ciclo suave `Guardia`. El render normaliza la pose animada antes de calcular su escala.

Conserva las reglas originales: no dispara; ofrece +8 % de alcance base y detección de enemigos ocultos a aliados dentro de 245 px, con escalado por nivel. Aturdirla suspende ambos efectos. La prueba de navegador verifica carga real, altura estable, alcance, detección y pérdida de los beneficios fuera del campo o durante el aturdimiento.
