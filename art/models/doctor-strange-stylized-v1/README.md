# Doctor Strange: prototipo estilizado

Base procedural de Blender a partir de la referencia del usuario. Meshy no completó la tarea 01a1c2d0-54f3-77ae-8b5b-47608d19c789.

Incluye capa, cuello alto, amuleto y clip Conjuro. No está integrado al combate. Pendientes: manos abiertas, proporciones, telas y sustitución de las formas rígidas heredadas del generador de Thor. No es un modelo terminado.
