# Mr. Fantastic · guardia de apoyo

Modelo generado y riggeado con Meshy desde la referencia aportada por el usuario. Blender adapta los brazos a la postura cruzada y añade el ciclo suave `Guardia`. Una malla, 3.135 triángulos, 24 huesos y un material con texturas 2K. El GLB pesa 11,7 MB; quedan pendientes optimización de texturas y LOD. Las manos cruzadas todavía admiten retoque fino.

En combate conserva el kit original de apoyo: +15 % de alcance exterior para aliados cercanos, sin disparos, con suspensión del efecto al estar aturdido. No incorpora ataques elásticos nuevos.

El render mide la pose animada inicial antes de normalizar la altura, para conservar las transformaciones del rig importado. La prueba de navegador comprueba altura estable durante el ciclo, carga real y reglas del aura.
